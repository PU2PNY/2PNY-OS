D-Star

Comandos D-Star pelo rádio / modo DR
_______I — informa o estado.
_______E — faz eco.
_______U — desconecta.
_______L — conecta ao refletor padrão.
XLX026DL — exemplo: conecta XLX026 ao módulo remoto D.
REF030CL — exemplo: conecta REF030 ao módulo remoto C.
Depois volte o destino para CQCQCQ.
DR/RPT1: indicativo do hotspot + o módulo local selecionado abaixo. RPT2: indicativo do hotspot + G. Em Icom simplex, use DUP+/DUP− com offset 0; DUP desligado pode não gerar cabeçalho de repetidora.
O padrão PU2PNY para uma nova configuração é B. O módulo remoto do refletor é independente.
Administração PU2PNY pelo rádio
Somente o indicativo configurado. Envie PNYARM e, dentro de 30 segundos, uma ação: PNYRBT reinicia; PNYOFF faz shutdown seguro; PNYDMR, PNYDST, PNYYSF, PNYP25, PNYNXD ou PNYPOC ativam um perfil já salvo. O armamento vale para uma única ação. Corte físico da alimentação exige hardware externo.
Configure o RPT1 do rádio com o indicativo do hotspot + este módulo. RPT2 permanece indicativo + G.
Rádio 1 usa 01, Rádio 2 usa 02. O Radio ID do seu rádio continua com 7 dígitos.
A API Key é usada para recursos de gerenciamento BrandMeister e não substitui a Hotspot Security. O PU2PNY não pede API Secret.
