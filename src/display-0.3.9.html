Nextion via MMDVM

Quando a Nextion está ligada pela porta da MMDVM, o PU2PNY usa o renderer nativo do MMDVMHost para evitar disputa pela porta. Nenhum HMI/TFT é gravado automaticamente.

PU2PNY Moderno V2 usa o renderer próprio em displays compatíveis. Em Nextion conectada pela MMDVM com HMI desconhecido, o sistema preserva o TFT e usa ON7LDS como fallback seguro. Layout ON7LDS e ON7LDS DIY são aplicados diretamente no MMDVMHost.
Foto no Nextion: o painel web pode usar foto dinâmica, mas Nextion Basic/Enhanced exibe imagens como recursos gravados no HMI. Para não sobrescrever seu HMI/TFT automaticamente, o PU2PNY usa avatar/indicativo e dados completos no Nextion atual. Foto dinâmica só será habilitada quando houver HMI compatível explicitamente instalado pelo usuário.

Compatibilidade Moderno V2

Nextion: interface vetorial dinâmica sem sobrescrever automaticamente o HMI/TFT. OLED SSD1306/SH1106: layout gráfico 128×64 com Standby/TX/RX. LCD HD44780/PCF8574: layout textual otimizado pela limitação física. Outros SPI/TFT só são ativados quando o driver/kernel é confirmado.
